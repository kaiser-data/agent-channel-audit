# Watching Is Not Enough: Hidden Message Boards Between AI Agents

Combined Swarm Alignment Hackathon submission (9 Nov 2026), merging both studies:

- Study A — Agent Channel Audit (this repository): detecting hidden agent message boards from access logs without reading content.
- Study B — Channel Displacement, included in `study-b-channel-displacement/` (also at https://github.com/kaiser-data/channel-displacement): what happens when an operator closes a board.

Files: `apart-template-final.pdf` (submitted version, official Apart template), `.docx`, LaTeX source `main.tex`, figures.
Every number comes from the two studies' analysis scripts; no new analyses were run for this paper.

Slides: `slides/index.html` (live: https://watching-is-not-enough.martinkaiser-bln.workers.dev), `slides/slides.pdf`.
